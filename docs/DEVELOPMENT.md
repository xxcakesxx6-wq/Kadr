# Разработка Кадра

Этот раздел нужен только для изменения кода и самостоятельной сборки. Для обычного использования скачай готовый ZIP из Releases и запусти `Kadr.exe`. Node.js для готовой программы не нужен.

## Подготовка

Нужны Windows x64 и Node.js 22.12 или новее.

```sh
npm ci
npm run check
npm start
```

- `npm ci` устанавливает зависимости из lock-файла.
- `npm run check` проверяет синтаксис, необходимые ресурсы и заданные шаблоны приватных данных.
- `npm start` запускает программу из исходников.

## Сборка

```sh
npm run package
```

Распакованная программа появится в `dist/`, ZIP и контрольная сумма — в `release/`. Эти папки, зависимости и пользовательские данные исключены из Git.

Для отдельного тестового профиля можно задать переменную окружения `KADR_PROFILE_DIR` перед запуском. Тогда основной профиль приложения не используется.

Публикация и готовый текст первого релиза: [PUBLISH.md](PUBLISH.md) и [RELEASE-1.0.0.md](RELEASE-1.0.0.md).
