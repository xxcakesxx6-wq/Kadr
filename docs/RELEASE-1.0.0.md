# Кадр 1.0.0

Первый релиз Кадра — приложения для выбора и просмотра кино на Windows, созданного на базе Lampa с собственным интерфейсом.

Разработано с помощью **OpenAI Codex**.

- Фильмы, сериалы, мультфильмы, аниме и дорамы в отдельных разделах.
- Поиск, фильтры и подборки мультфильмов по студиям.
- Избранное и история просмотров.
- Семь цветовых тем: от тёмной и светлой до Лемон, Тиффани, Матча и Аква.
- Встроенный плеер и выбор внешнего приложения.
- Проверка подключения к каталогу.

**Как запустить:** скачайте `Kadr-1.0.0-windows-x64.zip`, распакуйте архив целиком и откройте `Kadr.exe`.

Windows 10/11 x64. Установка не требуется. Для онлайн-возможностей нужен интернет; доступность источников зависит от сторонних сервисов.

`SHA256SUMS.txt` содержит контрольную сумму архива. Исходники соответствуют тегу `v1.0.0`.
